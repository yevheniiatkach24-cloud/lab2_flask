Про себе

Я студентка програмної інженерії, цікавлюся веброзробкою та створенням програмних застосунків. Вивчаю нові технології та розвиваю практичні навички програмування.

Освіта

Карпатський національний університет імені Василя Стефаника.

Спеціальність:інженерія програмного забезпечення.

Навички

  • Основи алгоритмізації та програмування
  • Робота з HTML і CSS
  • Робота з Git і GitHub
  • Створення адаптивних вебсторінок

Технології

HTML, CSS, Python, Flask, Bootstrap, Git.

Досвід роботи

Комерційний досвід у сфері програмної розробки поки що відсутній. Отримую практичний досвід під час виконання навчальних проєктів.

Проєкти

Навчальні проєкти з програмування, створення вебсторінок і роботи з базовими технологіями веброзробки.
